Object-Oriented Design

Polymorphic Expense Hierarchy

Abstract Base: Expense

Pure virtual function virtual string getType() const = 0; with virtual destructor ensures correct runtime polymorphic destruction.

Concrete: FixedExpense

Manages essential, recurring baseline overheads: apartment lease rent, insurance policies, and debt amortizations.

Concrete: VariableExpense

Models fluctuating monthly discretionary outflows: dining out, shopping, and entertainment subscriptions.

ExpenseModel.hpp C++17 Polymorphic Interface 
class Expense {
protected:
    string category, description;
    double amount;
    ExpenseClassification classification;
public:
    virtual ~Expense() = default;
    virtual string getType() const = 0;
    double getAmount() const noexcept { return amount; }
};

class FixedExpense : public Expense {
    string getType() const override { return "Fixed"; }
};
Robust Engineering

Deterministic Memory & RAII Vault

UP

std::unique_ptr

Enforces single-ownership semantics over dynamic objects stored in vector<unique_ptr<Expense>>, eliminating memory leaks and double-free hazards.

RA

Strict RAII Lifetimes

Resource Acquisition Is Initialization: file locks and file stream buffers (ofstream, ifstream) automatically flush and close upon scope exit.

MV

Move Semantics

Constructors ingest string tokens via std::move, avoiding unnecessary heap buffer copying when instantiating temporary transaction records.

✓ No Naked New / Delete ✓ Zero Heap Leaks ✓ Deterministic Stack Teardown

Greedy Capital Allocation

Multi-Goal Priority Waterfall Engine

PHASE 1

Pointer Harvesting

Collects non-owning raw pointers (FinancialGoal*) into an ephemeral vector, leaving the master heap storage intact.

PHASE 2

Priority Sorting

Sorts goals using a custom lambda comparator: Tier 1 (Emergency Fund) > Tier 2 (Hardware/Tools) > Tier 3 (Aspirational Targets).

PHASE 3

Waterfall Capital Dispatch

Directs 100% of monthly surplus into the highest-priority goal until satisfied, then cascades remaining funds into the next goal in sequence.

Waterfall Horizon Formula: Cumulative_Timeline(Goal_k) = ⌈ (Target_k − Funded_k) / Surplus + ∑(Months_Prior) ⌉
Exponential Growth Math

Compound Wealth & SIP Projection

ANNUITY DUE COMPOUNDING FORMULA:
FV = P × [ ((1 + r)^n − 1) / r ] × (1 + r)

• P = Monthly Investable Surplus (Rs.)

• r = Monthly Interest Rate = (Annual ROI % / 100) / 12

• n = Total Compounding Periods = Horizon × 12

• Net Wealth Gain = Projected Corpus − Total Capital Outlay

Division-By-Zero Protection

If the user specifies 0% annual return, the calculation gracefully switches to linear multiplication (surplus * totalMonths), preventing runtime arithmetic exceptions.

Fault Tolerance

Resilient Input Stream Architecture

Stream Failbit Recovery

When unexpected character strings are supplied to numeric inputs, cin.clear() resets stream flags, preventing infinite execution loops.

Buffer Flushes

Uses cin.ignore(numeric_limits::max(), '\n') to clear unread characters and residual newline bytes from the input buffer.

Whitespace Sanitization

getline(cin >> ws, str) strips leading carriage returns so text fields don't accidentally capture empty strings.

InputHelper.cpp Robust Input Validation 
double getNonNegativeDouble(const string& prompt) {
    double val;
    while (true) {
        cout << prompt;
        if (cin >> val && val >= 0.0) {
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            return val;
        }
        cout << "  [!] Invalid input. Positive number required.\n";
        cin.clear();
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
    }
}
